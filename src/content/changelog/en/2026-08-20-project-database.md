## Project database: add model data directly to conversations

You can now drag model elements, models, and drawings into a conversation, letting AI answer questions or perform tasks using the selected data. You can also choose when to refresh the project database instead of having it update continuously, **significantly improving overall performance**.

![Project database (placeholder)](/images/placeholder-16x9.svg)

## Skill folders

The My Skills page can now be organized into folders by project or discipline, making it easier for teams to find the workflow they need.

## New reasoning model

A new model suited to complex engineering tasks that need stronger reasoning is available and can be selected in Settings.

## Plan Mode: generate a plan before execution

For complex tasks, AI first produces an execution plan. You confirm the scope before execution starts, reducing back-and-forth revisions.

## Custom timeout

Adjust the per-task execution limit in Settings. Choose 300, 500, 700, or 1000 seconds to give complex work more time to complete.
