## Component generation, control panels, and version control

You can now build workflows that generate components and dedicated control panels. After generation, use drag-and-drop controls to fine-tune the component, connecting creation and refinement in one workflow. Version control helps you manage each change and preserve context for later edits.

![Component generation workflow demo (placeholder)](/images/placeholder-16x9.svg)

## Latest AI models now available

Several of the latest large language models are now available in Nexora AI, giving you more options for your workflows. Use them for requirements analysis, code generation, and workflow editing.

## Generate multi-version Skills in one click

In the Skill Editor, you can now generate Skills for multiple software versions in one click from the same workflow, reducing the need to adapt each Skill individually when teams work across versions.

## Report issues directly in the app

The new built-in Ticket System lets you submit issue reports directly from the app. Reporting becomes part of your workflow, making it easier to hand problems to the team for assistance.

## Support for the latest design software

Nexora AI now supports the latest version of the design software, so teams on new releases can run AI-generated code and Skills in their models. We will keep expanding version compatibility.
